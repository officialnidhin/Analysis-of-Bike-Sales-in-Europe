Analysis of Bike Sales in Europe 🚴

📊 Project Overview

This project focuses on analyzing bike sales data across Europe using Power BI. The objective is to identify sales trends, customer behavior, product performance, and important business insights.

🎯 Project Objectives

- Analyze overall bike sales performance
- Identify top-performing products
- Analyze sales across different regions
- Understand customer purchasing behavior
- Identify important trends and patterns

🛠️ Tools Used

- Power BI
- Microsoft Excel
- DAX
- Data Cleaning and Data Visualization

📁 Project Files

- Europe Bike Sales.pbix – Power BI dashboard and analysis file

📈 Dashboard Features

The dashboard includes:

- Total Sales Analysis
- Sales Performance by Region
- Product Category Analysis
- Customer Analysis
- Interactive Filters and Visualizations

💡 Key Insights

The analysis helps identify important sales patterns and supports better business decision-making through data visualization.
